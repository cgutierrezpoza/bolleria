# 🥐 Bollería · Fichas técnicas

Sitio web estático con las 28 fichas técnicas de la asignatura de Bollería (PGG1102), Escuela de Gastronomía Duoc UC, sede San Andrés de Concepción. Página desarrollada por Claudia Gutierrez Poza.

## Contenido
- **Portada** (`index.html`): presentación, enlaces a los sitios de Cocina, Salsas y Panadería, menú por áreas, recetario con filtros y buscador, explorador del laminado, glosario y contador de visitas.
- **5 áreas** (`areas/`): Masas dulces de levadura, Masas fritas, Croissantería, Masas hojaldradas, Cremas, rellenos y glaseados.
- **28 recetas** (`recetas/`): productos agrupados, multiplicador de receta (½×, 1×, 2×, 3×), porcentaje panadero, proceso paso a paso con progreso y puntos críticos.

## Enlaces a Cocina, Salsas y Panadería
Ya están configurados en `assets/js/enlaces.js`. Si alguna dirección cambia, edítala ahí.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo llamado `bolleria`.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio (*Add file → Upload files*).
3. Ve a **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En uno o dos minutos el sitio estará en `https://cgutierrezpoza.github.io/bolleria/`.
